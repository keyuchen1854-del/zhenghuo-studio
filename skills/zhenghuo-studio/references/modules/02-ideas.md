# generate-fresh-ideas｜脑洞搅拌机

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

触发：需要从文章、笔记、参考视频证据、商品简报中提出新角度。视频主链里只做角度探索；不重复写完整分镜或发布文案。单独使用时保留原来的选题扩写能力：用户选定角度并要求文章、帖子或备忘录，即直接交付完整稿，不再重发选题菜单。

先读来源，提取可复用观点或表达机制。可从反常识、个人故事、数据证据、操作方法、遗漏问题五类角度探索；根据素材选择有价值的角度，不为凑五类而编造。用户要求固定数量时给足有实质区别的候选，证据不足的类型明确说明。

每个角度给：一句话概念、受众问题、来源依据、如何连接真实商品、可见的开头画面、需要验证的假设。所谓个人故事要区分用户真实经历与虚构剧情；数据角度不能制造数字。多参考组合只借结构和表达方法，不把不同来源的身份、经历、数据混成事实。

产出：创意候选卡，交给总导演选案或反差编导发展。收到选定方案后停止继续扩散；需要新方向时只针对失败原因重开候选。
