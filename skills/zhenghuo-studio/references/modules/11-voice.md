# match-my-writing-style｜口吻分身

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

触发：用户要求像自己说话，或维护某个账号／达人的写作口吻。默认使用用户提供或明确指定的写作样本，不扫描无关私人内容。

提取语气、句长、常用词、开头结尾、标点、禁用词、节奏及不同渠道的表达差异。核实样本实际由用户创作，收到的邮件或他人的段落不能被当成用户口吻。样本不足时标为临时风格，不宣称已准确复现。维护可更新的风格卡；本次明确要求优先于历史习惯。单独使用时仍支持邮件、消息、帖子、文档的完整起草／回复／改写；发出内容是另外的动作，不随写稿自动发生。

对现有台词或文案提出风格改稿，保持事实、目标语和信息意图。风格稿中的第一人称经历必须有依据；不能从样本迁移真实姓名、客户信息、商业机密或他人的经历。

产出：风格卡或带修改说明的风格版本。台词改变后交回翻译／口播时间检查；文案改稿回文案模块。风格不拥有商品事实和最终台词的独立副本。
