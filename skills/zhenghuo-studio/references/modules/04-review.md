# get-more-perspectives｜挑刺评审团

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

触发：方案有实质取舍、成本风险，或用户明确要多视角评审。小而可恢复的决定直接给简短建议。

围绕同一个问题，从执行、风险、创新、观众、成本五个角度检查；用户可增加或替换角色。先给建议与成立条件，再给各角度的支持／反对／有条件意见和关键分歧。缺乏决定性证据时允许保留判断，不为显得果断而强行投票。

明确这些是同一模型的分析视角，除非确实另行调用了独立评审。模拟投票、共识和个人偏好都不等于真实观众或独立验证。成本、效果、时长只引用实测或明确标注的估计。

产出：按严重程度排序的问题、依据、责任岗位、建议修改及是否阻止进入下一阶段。评审只提出修改请求，不直接改写已确认的商品事实或镜头。外部资料按任务需要与现有授权读取；用户未授权时不自动访问邮箱或发送评审意见。
