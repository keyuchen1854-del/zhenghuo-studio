# 视频内容逐句翻译｜口播翻译官

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

触发：理解原片口播、核对目标语台词、制作双语对照或本土化。语言识别不证明拍摄国家或销售市场。

对原片做逐句转写与翻译时，保留原词、时间码、听清程度、源语言和中文解释；复用已有转写，不再次编造另一套。用户要求新市场改写时另建目标语版本，原文仍保留。

本土化保持原意与商品事实，允许自然语序和表达调整，不增添促销、经历或功效。给目标语、中文核对及必要术语说明。口播时长按实际目标语配音或明确标注的估算核对；中文字数比例只可辅助检查信息量，不能证明外语一定说得完。

产出：统一台词表、术语表、口播时间检查与不确定片段。超时退回对应台词修改，意义或卖点变化交总导演确认。未经听审不能写“母语审校通过”或“完美对口型”。
