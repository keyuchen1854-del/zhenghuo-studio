# 故事板-提示词｜分镜施工图

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

触发：创意或适配脚本已选定，需要落到可执行镜头。维护最终镜头计划，不重新选择故事方向。

读取选案、商品事实、台词和单元计划。先统一人物、商品、场景、机位方向、左右手、穿戴状态和声音设定；根据镜头需要记录可见细节，未知材质不能从图片猜定。

逐镜给：编号、计划使用时长、单元归属、目的、构图／运镜、动作起点与顺序、结束状态、商品可见部位、台词编号、声音、字幕、参考角色、连续性与生成难点。复杂动作拆成可理解的片段；镜头切换和段内动作时长要留出空间。

输出图像任务说明和视频动作说明，交给统一提示词编译；不硬编码 Image 2、Seedance 或 Kling。图像说明描述一个可画出的状态，视频说明描述从这个状态发生的运动，避免用静态图提示词承担整段剧情。

产出：分镜计划与连续性卡。需要调整剧情时给总导演明确变更建议；不为满足接口而悄悄删去商品演示。
