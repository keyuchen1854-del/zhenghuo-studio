# 关键帧改写复刻视频｜原片拆解台

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

原名：三合一复刻。保留逐句转写、精确分镜、改写和图生视频提示词的完整用途；作为工具箱子模块时，原片证据只建立一次，后续改写与提示词复用共用岗位。

先实际读取完整视频与必要音轨，确认真实时长、时间基准、切点、口播、字幕、动作和商品状态。听不清、遮挡或切点不确定的地方标明，不补成确定内容。每个参考单独编号和保存。

普通参考提炼输出足够支持创意的证据表；用户要求精确复刻时保留原来的 43 列完整导出与逐句证据表，源镜头覆盖完整时间线，不能用模型分段反推伪造原切点。原始观察字段保持不变，改写台词、选帧建议以关联字段追加。字段与时长校验见[精确字段与时长规则](../precise-fields.md)。

参考关键帧必须与真实动作对应。竞品图只提供动作／构图参考时明确角色；不能把竞品当新商品的身份锚点。商品细节以实际参考和经核实资料为准，缺失配件不得凭想象添加。

产出：原片证据、句子／镜头映射、原关键帧位置、可借鉴机制与禁改项。翻译复用同一份转写；商品改写交给裂变模块或反差编导，最终镜头交给故事板，生成提示词由统一编译步骤输出。单独调用本技能时按这条内部子链交付完整结果。
