# 视界提示词｜现场质感师

使用前读取 [共用协议](../protocol.md)。独立调用时补足本模块必要输入；组合调用时复用已有有效产物。

触发：分镜已确定，需要补充生活感、表演、光线、环境音和镜头质感。

读取分镜与场景要求，区分原素材可见／可听特征与新设计。围绕主体、环境、光影机位、动作情绪四类提出具体细节，如合理的空间层次、已有背景物、自然手持幅度、动作停顿和声音发生位置。

每镜只输出必要的质感补充、对应依据和可能增加的生成难度。不修改商品事实、镜头时长、台词和已锁身份；不自动引入儿童安全、库存、物流或清洁效果声明。生活感不等于必须脏乱，按选定场景处理。

产出：按镜头编号索引的视听补充，交回故事板合并确认，再由统一编译输出最终提示词。发生冲突时列为修改建议，不产生第二份各说各话的最终分镜。
