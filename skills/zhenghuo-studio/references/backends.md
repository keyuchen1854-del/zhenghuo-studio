# 模型交接与计划格式

图片在本机生成，视频通过实际配置的 H3 API 生成。工具箱不附模型权重、密钥、私人配置，也不会安装服务或启动付费生成。

## 本地图片

1. 发现当前环境已安装的图片模型、启动方式与工具，核实其是文生图还是图片编辑。Qwen-Image-Edit-2511 可作为已有图片编辑环境的候选；没有底图时不能假定支持纯文生图。
2. 本机服务已启动时用 `studio.py doctor --local-url http://127.0.0.1:实际端口` 只读核对队列。该命令不证明模型权重、节点或显存满足要求。
3. 读取实际工具说明，核对模型、输入角色与本地队列，再按本次授权生成。先代表图，商品结构、手部遮挡、人物和构图通过才复用或扩展。
4. 记录工具版本、参数、任务编号、输入输出哈希与审看结果。超时先恢复原任务，不重复提交；不停止其他任务。

如环境已有 `qwen_local.py`，使用它实际提供的 `check`、`render`、`resume` 命令；先检查其 `--help`。工具路径是本机配置，不写入公开包。此工具箱没有内置模型下载器。

## H3 API

`H3` 是路线选择，不足以唯一确定服务商、账号、模型标识或参数。执行前从当前接入方文档、可用工具和账号能力核实图／视频／音频参考、时长、画幅、分辨率、声音与计费。

复用已有经过验证的 H3 执行器，并遵守该执行器的分镜、费用与上传批准检查。需要原视频的复刻执行器只用于匹配的任务；原创路线缺少图生视频入口时暂停提交，报告具体能力缺口，不传黑片绕过要求。载荷允许省略视频字段不等于服务端能力经过验证。

提交前，把完整请求与参考素材版本绑定到批次批准：服务商、模型、每次生成时长、数量、分辨率、比例、单价依据、预估费用、最高预算和重试范围。批准与执行参数不匹配时不得提交。密钥由实际工具从环境或安全存储读取，不写进提示词、项目文档、Git 或日志。

本工具箱的 `prepare-handoff` 输出是准备资料，不是批准记录；它不会发送 API 请求。运行环境没有 H3 执行器时，先完成接入及获批的小样验证，不能把准备资料称为已生成视频。

## 计划示例

以下数据是结构示例，演示 2 个片段的长度计算；服务商、模型及允许时长必须填真实核实结果。不要把示例当作 H3 的当前官方参数。初始化出的空计划有意不能通过预检。

```json
{
  "schema_version": "1.0",
  "project_id": "demo",
  "route": "original",
  "market": "目标市场",
  "language": "目标口播语言",
  "target_duration_sec": 10,
  "image_backend": "local",
  "video_profile": {
    "backend": "h3-api",
    "provider": "填写实际服务商",
    "model": "填写实际模型标识",
    "resolution": "填写实际分辨率",
    "allowed_durations_sec": [5],
    "evidence": "填写实际参数来源与账号核对记录",
    "verified_at": "填写核实日期"
  },
  "segments": [
    {"id":"S01","generation_duration_sec":5,"use_start_sec":0,"use_end_sec":5,"transition_overlap_sec":0,"prompt":"storyboard/S01.txt","image":"assets/S01.png"},
    {"id":"S02","generation_duration_sec":5,"use_start_sec":0,"use_end_sec":5,"transition_overlap_sec":0,"prompt":"storyboard/S02.txt","image":"assets/S02.png"}
  ]
}
```

素材路径相对于计划文件，可引用已有获准素材。每段可选 `reference_video`、`dialogue_audio`。每项可附同名加 `_sha256` 的哈希字段，如 `image_sha256`；存在时校验版本未变。`prepare-handoff` 总会记录实际素材哈希与原计划哈希。交接记录含本机绝对路径，应保存在项目工作目录，不能放进公开仓库。

时长计算见 [精确字段与时长规则](precise-fields.md)。预检不解码媒体，也不能识别商品错误；内容审看和输出文件的实际媒体检查仍须执行。
